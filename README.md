# Pascal Programming

A collection of Pascal programs covering fundamental programming concepts, syntax, and problem-solving exercises.

This repository contains my practice programs while learning Pascal programming, organized topic-wise for easy reference and revision.

## 📚 Topics Covered

- Basic Pascal Programming
- Arrays
- Operators and Expressions
- Conditional Statements
- Loops and Iterations
- Functions
- Procedures
- Pointers
- Records and Structures
- Switch Case / Case Statements

## ⚙️ How to Run

You can compile and execute these programs using the Free Pascal Compiler (FPC).

**1. Install Free Pascal**

Download it from: https://www.freepascal.org/

**2. Compile a program**

```bash
fpc basic.pp
```

**3. Execute the compiled program**

```bash
./basic
```

Replace `basic.pp` with the filename of the program you want to execute.
